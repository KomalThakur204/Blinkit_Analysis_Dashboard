# Blinkit Sales Analysis Dashboard Using MS Excel
## Objective:
The objective of this project is to create an Excel-based interactive sales analysis dashboard that provides key insights into sales performance, outlet types, item categories, and various business metrics. The dashboard helps in understanding trends, identifying patterns, and making data-driven decisions. The data used in this dashboard is entirely mock/sample data and does not represent real company data.
## Dataset Used:
<a href="https://github.com/KomalThakur204/Blinkit_Analysis_Dashboard/blob/main/Blinkit%20sales%20analysis.xlsx">Dataset</a>
## KPI requirements:
- Total Sales: The overall revenue generated from all items sold.
- Average Sales: The average revenue per sale.
- Number of Items: The total count of different items sold.
- Average Rating: The average customer rating for items sold.
## Chart Requirements:
- Total Sales by Fat Content:
  Objective: Analyze the impact of fat content on total sales.
- Total Sales by Item Type:
  Objective: Identify the performance of different item types in terms of total sales.
- Fat Content by Outlet for Total Sales:
  Objective: Compare total sales across different outlets segmented by fat content.
- Total Sales by Outlet Establishment:
  Objective: Evaluate how the age or type of outlet establishment influences total 
  sales.
- Sales by Outlet Size:
  Objective: Analyze the correlation between outlet size and total sales.
- Sales by Outlet Location:
  Objective: Assess the geographic distribution of sales across different locations.
- All Metrics by Outlet Type:
  Objective: Provide a comprehensive view of all key metrics (Total Sales, Average 
  Sales, Number of Items, Average Rating) broken down by different outlet types.

- Dashboard Interaction <a href="https://github.com/KomalThakur204/Blinkit_Analysis_Dashboard/blob/main/Dashboard.png">View Dashboard</a>
## How to use:
- Clone or Download the repository.
- Open the Excel file in Microsoft Excel.
- Interact with the dashboard using available filters to analyze different sales   
  aspects.
- Modify the dataset to see real-time updates reflected in the dashboard.
